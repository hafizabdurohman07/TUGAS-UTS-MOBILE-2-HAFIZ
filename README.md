## SAYA MEMBUAT APLIKASI INI, UNTUK MEMENUHI TUGAS UJIAN TENGAH SEMESTER ( MATAKULIAH PEMROGRAMAN MOBILE 

## Smart Notes by Hafiz adalah aplikasi manajemen catatan berbasis Android yang dirancang dengan antarmuka Premium (Navy & Gold Theme). Aplikasi ini tidak hanya sekadar menyimpan teks, tetapi juga dilengkapi dengan fitur cerdas seperti AI Voice-to-Text, keamanan biometrik/PIN, pengingat alarm, dan statistik penggunaan yang interaktif.

# 🌟 Fitur Utama :

## • Premium UI/UX: Tampilan mewah dengan aksen Navy Blue dan Gold.

## • AI Voice to Text: Mencatat ide hanya dengan suara menggunakan teknologi Speech-to-Text.

## • Security (Private Vault): Amankan catatan rahasia Anda dengan kunci PIN.

## • Smart Reminder: Setel alarm pengingat agar tidak melewatkan tugas penting.

## • Multimedia Support: Tambahkan gambar ke dalam catatan Anda.

## • Organisasi Cerdas: Fitur Kategori (Kuliah, Kerja, Ide, dll), Arsip, dan Tempat Sampah (Soft Delete).

## • Data Analytics: Lihat distribusi kategori catatan Anda melalui grafik Pie Chart yang interaktif.

## • Export to PDF: Unduh semua catatan Anda ke dalam format dokumen PDF profesional.

## • Dark Mode Support: Nyaman di mata dengan dukungan tema gelap.

# 📱 Penjelasan Halaman & Alur Kerja :

# 1. Splash Screen & Onboarding :

## • Splash Screen: Menampilkan identitas brand dengan logo mewah dan animasi loading. Menggunakan logika cerdas; jika pengguna sudah pernah masuk, halaman ini akan langsung melompat ke Beranda.

## • Onboarding: Memberikan pengenalan fitur utama kepada pengguna baru sebelum mulai menggunakan aplikasi.

# 2. Main Activity (Halaman Utama) :

## • Dashboard Catatan: Menampilkan daftar catatan dalam bentuk Staggered Grid (2 kolom) yang rapi.

## • Quick Search: Mencari catatan berdasarkan judul atau isi secara real-time.

## • Navigation Drawer: Menu samping untuk akses cepat ke kategori, statistik, dan profil.

## • Navigation Bottom Bar: Akses cepat ke Beranda, Pencarian, Favorit, dan Pengaturan.

## • PIN Protection: Menampilkan dialog PIN secara otomatis jika pengguna mencoba membuka catatan yang terkunci.

# 3. Add & Edit Note (Editor Premium) :

## • Rich Editor: Tempat menuangkan ide dengan input judul dan konten yang luas.

## • AI Voice Input: Tombol mikrofon yang mengubah suara menjadi teks secara otomatis.

## • Category Picker: Memilih label kategori menggunakan BottomSheet Grid yang mewah.

## • Management Tools: Tombol khusus untuk menambah gambar, menyetel alarm, mengarsipkan catatan, mengunci dengan PIN, dan membuang ke tempat sampah.

# 4. Stats Activity (Analitik) :

## • Dashboard Insight: Menampilkan kartu ringkasan jumlah total catatan, catatan favorit, dan catatan privat.

## • Interactive Chart: Menggunakan PieChart untuk visualisasi distribusi kategori (misal: berapa persen catatan Kerja vs Kuliah).

# 5. Profile Activity :

## • User Identity: Mengatur Nama, Email, dan Foto Profil.

## • Persistent Storage: Foto profil disalin ke penyimpanan internal aplikasi agar tetap muncul secara permanen meskipun galeri asli dihapus.

# 6. Settings Activity (Konfigurasi) :

## • Dark Mode Switch: Mengaktifkan tema gelap untuk seluruh aplikasi.

## • Master PIN: Mengatur satu PIN utama yang berlaku untuk seluruh catatan terproteksi.

## • Backup to PDF: Mengonversi seluruh isi database menjadi file PDF yang tersimpan di memori HP.

## • Wipe All Data: Fitur penghapusan database secara total dan permanen.

# 🛠️ Teknologi yang Digunakan :

### • Language: Java

### • Database: Room Database (SQLite) - Untuk penyimpanan data lokal yang cepat dan terstruktur.

### • UI Framework: Material Design 3 (M3) - Untuk komponen visual yang modern.

### • Analytics: MPAndroidChart - Untuk visualisasi grafik statistik.

### • Architecture: MVVM (Model-View-ViewModel) - Menggunakan LiveData dan ViewModel untuk sinkronisasi data yang reaktif

### • Persistence: SharedPreferences - Untuk menyimpan konfigurasi user, tema, dan profil.

### • API Android:
       
        ### ◦ AlarmManager & NotificationChannel (Pengingat).
        
        ### ◦ RecognizerIntent (AI Voice-to-Text).

        ### ◦ PdfDocument (Ekspor Dokumen).
